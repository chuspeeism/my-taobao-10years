# 我的淘宝十年 · 十年小铺

把自己的淘宝记录，整理成一间可以离线保存的小店：不同主线、不同店名和配色，带商品货架、年度小票、订单日历、配乐建议和愿望清单。只读到几年，就写几年。

## 在豆包电脑版安装

把这个仓库地址复制给豆包，说：

> 帮我安装 GitHub 上 chuspeeism 的 my-taobao-10years Skill

仓库地址：https://github.com/chuspeeism/my-taobao-10years。

标准 Skill 在 `skill/my-taobao-10years/`。安装时保留整个目录，包含 `SKILL.md`、`scripts`、`references`、`assets` 和虚构示例。用户不用写代码、配密钥或搭服务器。生成工具只需要 Python 3.9 以上，无第三方 Python 包；缺少 Python 时豆包会先说明。安装器能否完整取到附件、个人版能否执行，仍要以实际安装为准。

5. “把问问小豆藏起来，给我一个能发给朋友的单文件。”

登录、扫码和验证码由本人完成，遇到滑块会停。音乐推荐不附商业歌曲音频；模板另带7首已署名的授权纯音乐，页面也接受你自己有权使用的文件，首次点击页面或按键后开始，能随时静音。问答默认离线，不能回答的问题可以复制到豆包继续问。

## 先看示意

`skill/my-taobao-10years/assets/template/index.html` 可以双击离线打开；画面上的用户、商品、品牌、金额均为**虚构示意**，商品图由几何图形绘制。`examples/` 有养猫、母婴、户外三套模拟输入，不能当成真实订单或真实读取能力的证明。

真实数据只保存在你的任务目录，不写入 Skill。网页默认去掉原订单号、姓名、账号、地址和手机号；商品与日期仍可能属于隐私，公开前自己确认。文件夹版和单文件版均可离线用，本地打卡不会自动同步到另一台电脑。

## 维护者

脚本入口：`scripts/shop.py analyze / build / check / bundle`；数据格式、文案和逐项验收在 Skill 的 `references/` 中。使用新输出目录生成下一版，不覆盖旧成果。

第三方仅随包附带 three.js r170（含 RoundedBoxGeometry、RoomEnvironment），遵循其 MIT 声明；项目模板和自绘示意素材的来源见 `SOURCES.md`。本项目未附开源许可证，欢迎个人安装使用。
